01 · AI Builds

The systems I build to run People Operations

I don't treat AI as a stand-alone experiment. For each workflow below I design the process, the prompts, the system integrations, the human checkpoints, and the adoption path — then I run it myself, on real employee-lifecycle work.

A safeguard, by design: every workflow below keeps a human decision point before anything writes to an employee record or leaves as a document. AI drafts, routes, and assembles evidence; approval and judgment stay with a person — usually me.

Employee Lifecycle Change Agent

Claude + n8n · Rippling

Routes approvals and triggers HRIS record updates for employee-lifecycle transactions — promotions, comp changes, transfers — eliminating manual processing steps and creating one consistent path from request to system update.

TriggerEmployee change request submitted
InputsEmployee record, approval chain, policy rules
Agent actionValidates fields, routes approval, drafts the update
Human approvalManager / HR sign-off before any system write
OutcomeConsistent request-to-update path, no manual re-entry
